# PESCI practice library

Only original, clearly labelled educational scenarios belong here. These are not official exam items, validated scoring tools, medical advice or a prediction of success. PESCI is a position-specific structured clinical interview, not MCQ. Check the selected provider's current handbook before adding an official-format mock. Practice timers are user-configurable learning settings, not asserted official timing. A qualified Australian clinician should review clinical content before reliance. Never commit patient data or recalled/leaked exam content.

Each JSON record carries stable ID, version, topic, provenance, review status, prompts and reflection rubric. Clinical images require clear reuse rights and accessibility text. Text-to-speech is a reading aid, not an examiner.

Current authored topics: urgent communication (COMM-001), young-infant fever (PAED-002), adolescent abdominal pain (ABDO-003), immediate mental-health safety (MH-004), diabetes medicine safety (DM-005), older-child fever/safety-netting (PAED-006), abdominal/possible acute scrotal presentation (ABDO-007), collaborative diabetes care (DM-008), and mental-health continuity (MH-009). These are alternative learning cases, not a prescribed official examination set.

Research basis and limits: `docs/research/pesci-practice.md`. Keep the public clinical case library separate from private learner answers/reflections. Adding a JSON file does not itself register it in an API that uses explicit imports.
