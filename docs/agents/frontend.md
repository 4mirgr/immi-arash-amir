# Frontend
Own src/, index.html, vite.config.js. Read API contract from server/README if present. RTL responsive dark navy, restrained neon match indicators, accessible controls. Distinct GP/PESCI and specialist workspaces. Never put secrets or raw CV data in bundle; demo selector is not auth. Verify npm run build. Hand off endpoint/property changes only.

Reusable display helpers: MixedText isolates Latin runs in RTL prose; DualCalendar uses canonical ISO instant with Tehran/Jalali and Australian/Gregorian views. GoogleSendPanel previews/queues are pinned to person+mailbox+provider identity. Preserve those guards when changing layout. Theme and font size are separate per profile in browser storage.

Sync continuity: preserve same-owner loaded content on transport failures, label stale, never turn a status-fetch error into OAuth disconnect. Do not remount an open editor during polling. `auth-session.mjs` owns memory-only renewal; `api.js` preflights once without replaying mutations. UI checkpoint IDs only via `workspace-checkpoint.mjs`, keyed by verified owner UUID/profile; no text/tokens/recipients/consent. Optional regression: `python tests/browser/check_sync_continuity.py` (Playwright+Chromium installed).

Localization: English UI must be complete, including dynamic errors, attributes/options, public analysis and dates/numbers. See docs/LANGUAGE.md only when changing localization. Put human translations in the relevant small role catalog under src/locales; use interfaceLocale() for displayed formats and explicit option values. Preserve raw private/source content and live editor state. Verify the English UI census after adding UI copy; do not rely on dictionary size.
