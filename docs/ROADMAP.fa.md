# نقشهٔ تحویل

این فایل تفاوت هدف نهایی و نسخهٔ فعلی را ثبت می‌کند. وجود یک منو به معنای پیاده‌سازی اتصال آن نیست.

| بخش | نسخهٔ فعلی | کار باقی‌مانده |
|---|---|---|
| دو فضای کاری | انتخاب پروفایل محلی | ورود واقعی دو حساب، session، RLS و آزمون امنیت |
| کلینیک‌ها | import خصوصی، شناسهٔ ثابت، ادغام ایمیل، فیلتر | غنی‌سازی آدرس، راستی‌آزمایی MMM/DPA و supervisor |
| کشف شغل | دادهٔ تماس قابل مرور | collectors رسمی هر ایالت، آگهی‌های فعال، زمان‌بندی، حذف منقضی‌ها |
| رتبه‌بندی | اطلاعات موجود و نامعلوم شفاف | scoring توضیح‌پذیر با وزن‌های قابل تغییر؛ بدون درصد ساختگی |
| ایمیل | پیش‌نویس محلی | Gmail OAuth، attachment، preset نسخه‌دار، default CV، ارسال گروهی و queue |
| inbox | اتصال غیرفعال | دریافت incremental، thread mapping، تحلیل قوی/متوسط/ضعیف با شواهد |
| CV | متن خصوصی قابل استفاده | استخراج ساختاریافته، نسخه‌بندی، قالب‌های DOCX/PDF، achievement تأییدشده |
| رشد رزومه | هدف ثبت‌شده | پیشنهاد دورهٔ معتبر و هزینه/ارزش، Calendar دوطرفه و تعارض‌ها |
| اعلان‌ها | تنظیمات اتصال | Telegram bot، اعلان موقعیت و خطا و امکان توقف |
| PESCI | تمرین آموزشی اولیه، کتابخانه در git | منابع provider، مرور بالینی، پوشش موضوعی، mock و گزارش پیشرفت |
| مسیر امیر | پروفایل جدا و یادداشت رسمی تخصص | دریافت CV و مدارک، بررسی board/non-board و فرصت‌های شخصی |
| AI agents | تقسیم توسعه و نقش‌ها در مخزن | workerهای پایدار cloud با API، صف، بودجه و observability |
| زیرساخت | اجرای محلی و CI | حساب‌ها، secrets، adapter ابری، backup، deployment و دامنه .ir |

ترتیب پیشنهادی تکمیل: احراز هویت و دیتابیس ابری → Gmail و CV → کشف شغل و اعلان → تحلیل پاسخ → کتابخانه و mock گسترده. فایل‌ها و مدارک امیر پس از دریافت، جدا از آرش وارد می‌شوند. ایجنت‌های توسعهٔ این نشست پس از پایان نشست به شکل دائمی اجرا نمی‌شوند.
