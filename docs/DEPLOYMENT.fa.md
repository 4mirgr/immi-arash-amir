## دو کار شخصی لازم برای ورود

۱. در صفحهٔ سایت با ایمیل مجاز خودتان رمز تعیین کنید و دکمهٔ «ساخت حساب و ارسال ایمیل تأیید» را بزنید. سپس لینک ایمیل را تأیید کنید و به سایت برگردید. رمز را در چت نفرستید. هیچ حساب واقعی با رمز ساختگی ایجاد نشده است.

۲. تنظیم Site URL در [Supabase Auth URL Configuration](https://supabase.com/dashboard/project/waxpjylnvwqdlktayyww/auth/url-configuration) را برابر آدرس سایت بالا قرار دهید و همان آدرس را به Redirect URLs اضافه کنید. اتصال مدیریتی موجود ابزار تغییر Auth URL را ارائه نمی‌کند؛ این تنظیم به داشبورد مالک نیاز دارد. تا قبل از آن، ممکن است پس از تأیید ایمیل به localhost هدایت شوید؛ تأیید انجام شده و می‌توانید دستی به نشانی سایت برگردید.

## اتصال‌های باقی‌مانده

Google متصل به چت، حساب امیر است؛ توکن این اتصال در اختیار سایت نیست. Gmail/Drive/Calendar در خود سایت، Google OAuth client و callback مستقل و رضایت هر پزشک را لازم دارند. سایت هنوز ایمیلی نمی‌فرستد و صندوق ورودی نمی‌خواند. Telegram، AI و collector دائمی منابع نیز هنوز متصل نیستند. ثبت دامنه .ir و DNS انجام نشده و دسترسی از ایران باید با شبکهٔ واقعی آزمایش شود.

## شواهد بررسی

- تست Python برای import، CV، preset/queue، RSS و قرارداد HTTP
- تست Node برای توکن، مالکیت Worker، خروجی DOCX و heartbeat
- SQL روی Supabase واقعی: رد دسترسی ناشناس/کاربر دیگر، مجوز roster خصوصی، snapshot/preset RPC و onboarding پس از verified-email؛ داده‌های مصنوعی rollback شدند.
- مرورگر روی سایت منتشرشده: فرم ورود/ثبت‌نام، نبود جدول خصوصی، عدم خطای JS، پاسخ401 به bootstrap بدون ورود
- Security Advisor: نداشتن policy روی roster خصوصی یک INFO عمدی برای deny-all است. هشدار Leaked Password Protection نیز وجود دارد؛ طبق مستندات فعلی Supabase این قابلیت مخصوص Pro و بالاتر است و برای حفظ پلن رایگان فعال نشده. اعتبارسنجی حداقل ۱۲ کاراکتر در UI اجرا می‌شود؛ سیاست سروری رمز از تنظیمات Auth مالک قابل تغییر است. این مرور جای ممیزی کامل مستقل را نمی‌گیرد.

هنوز ورود دو حساب واقعی از ابتدا تا انتها با تأیید ایمیل آزمایش نشده است. محدودیت سهمیهٔ ایمیل Supabase و دسترس‌پذیری شبکه ممکن است روی ثبت‌نام اثر بگذارد. برای داده‌های ورودی یک backup محلی خصوصی ایجاد شد؛ backup عملیاتی خودکار cloud هنوز تنظیم نشده است.

به‌روزرسانی همین نشست: ثبت‌نام و تأیید ایمیل امیر و ایجاد عضویت amir در دیتابیس واقعی مشاهده شد. آرش هنوز باید حساب خودش را بسازد. CI مخزن برای commit cf59631 موفق شد (۳۱ تست Python، ۱۶ تست Node، build و bundle).
