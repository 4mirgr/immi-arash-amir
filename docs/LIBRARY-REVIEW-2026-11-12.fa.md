# بازبینی با Codex Extended Library

۱۲ نوامبر۲۰۲۶؛ دامنهٔ کار، اصلاح و نگه‌داری سازگار سایت دو پزشک با حفظ ساختار اصلی است.

## راهنماهای افزوده‌شده

فایل ارسالی در ریشهٔ مخزن نگه‌داری شد. از آن فقط دو مدخل مرتبط انتخاب و متن اصلی و فایل‌های لازم از commit مشخص خوانده شدند: `code-reviewer` از `alirezarezvani/claude-skills` و `github-actions` از `sickn33/agentic-awesome-skills`. دو اسکیل سازگار با پروژه در `.agents/skills/` اضافه شدند؛ منابع، مجوزها و هش‌ها در `sources.lock.json` هستند. هیچ ابزار پولی، loader اجرایی ناشناخته یا نصب سراسری روی مک انجام نشده است. مستندات خارجی به دستورهای جاری و مجوزهای همین پروژه تطبیق داده شدند؛ مطالعهٔ راهنما به معنی اجرای تمام مثال‌هایش نیست.

## ایرادهای اصلاح‌شده

- یک فراخوان با عبارت Open و تاریخ شروع آینده زودتر از موعد باز معرفی می‌شد؛ تاریخ شروع صریح یا نامشخص اکنون جلوی این ادعا را می‌گیرد.
- اشارهٔ منفی به پوشش شهریه ممکن بود به‌دلیل نام بورس شهریه، بستهٔ کامل محسوب شود؛ عبارت‌های صریح نفی پوشش، طبقه‌بندی فول‌فاند را مسدود می‌کنند.
- دادهٔ خراب در یکی از ردیف‌های چک‌لیست می‌توانست کل پنل فاند را از دسترس خارج کند؛ ردیف نامعتبر کنار گذاشته می‌شود و پیشرفت معتبر باقی می‌ماند.
- برنامهٔ عمومیِ بورسِ بسته در فیلتر فراخوان مشخص ظاهر می‌شد؛ نوع برنامه مستقل از بسته‌بودن حفظ می‌شود.
- پاسخ دیررس polling پیش از ذخیره می‌توانست انتخاب تازه ذخیره‌شده را بازنویسی کند؛ کنترل نسخهٔ خواندن/ذخیره این رقابت را متوقف می‌کند.
- تابلوی مشترک هنگام نوشتن بازخوانی می‌شد و انتخاب منطقهٔ زمانی استرالیا اثر لازم نداشت؛ بازخوانی حین تغییر متوقف و منطقهٔ زمانی به کنترل تقویم متصل شد. هنگام انتشار، کنترل زمان نیز قفل می‌شود.
- یک تصویر آزمون مرورگر در مسیر ثابت ماشین محلی ذخیره می‌شد و روی GitHub شکست خورد؛ خروجی به پوشهٔ موقت همان آزمون منتقل شد. آزمون حذف یا اختیاری نشد.

## نگه‌داری خودکار

پیش از این، CI فقط push/PR و آزمون‌های بدون مرورگر داشت. اکنون بررسی روزانه و دستی، شش مسیر مصنوعی مرورگر، بررسی هش اسکیل‌ها، audit و بررسی خواندنی ورود و API خصوصی اضافه شده است. نگه‌داری هفتگی/دستی فقط lockfile مربوط به patch پایدار را پس از بررسی کامل می‌پذیرد؛ نسخهٔ اصلی/فرعی، package جدید، تغییر منبع، رفتار نصب جدید و main جابه‌جا‌شده رد می‌شوند. راهنمای دقیق در `AUTOMATIC-MAINTENANCE.fa.md` است.

همین روند ابتدا Vite۶٫۴٫۵→۶٫۴٫۶ را بدون تغییر manifest انتخاب کرد؛ پس از نصب و آزمون‌ها اعمال شد. اجرای دستی واقعی workflow نگه‌داری روی GitHub نیز موفق بود و به‌علت نبود patch تازه، commit اضافی نساخت. این نتیجه به معنی موفقیت تمام به‌روزرسانی‌های آینده نیست.

## مرزهای باقی‌مانده

این نوبت به طراحی بنیادی، اهداف GP/Level1/PESCI آرش، مسیر تخصص/پژوهش امیر یا جداسازی Google/LinkedIn/CV دست نزد. اسکیل جدید، مجوز API شبکهٔ کامل LinkedIn ایجاد نمی‌کند. پشتیبان کامل و بازیابی مجزا، بازبینی انسانی محتوای بالینی، پوشش منابع مسدود/PDF و بررسی شخصی شرایط دانشگاه همچنان باید مطابق فهرست ناتمامی‌ها تکمیل شوند؛ ادعای تکمیل این موارد نمی‌شود.

برای انتشار کاملاً خودکار کدهای آیندهٔ Worker، CI هنوز به Secret مستقل و محدود Cloudflare نیاز دارد؛ اتصال مدیریتی موجود برای انتشار این نوبت استفاده شد و کلید آن استخراج یا وارد GitHub نشد. به‌روزرسانی داده‌های زمان‌بندی‌شده و آزمون/patch خودکار به آنلاین‌بودن مدیر وابسته نیستند؛ تولید ویژگی جدید و تغییرات پزشکی بدون بازبینی خودکار نمی‌شوند.
