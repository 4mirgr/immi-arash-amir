# International medical/academic CV output policy

No single CV template is accepted by every regulator or university. Follow the receiving institution's required template first; otherwise use a clean, searchable A4 single-column document, consistent dates, legible typography and standard headings. Avoid decorative charts, embedded photos or unnecessary sensitive identifiers unless expressly required. Keep an editable text/source copy.

Use only verified/current own-profile facts. Typical clinical order: name/contact; concise professional summary and current status; registration/examinations with exact authority/date/status; clinical employment and responsibilities in reverse chronology; education/training; relevant skills, CPD and certificates; research/publications/teaching; referees where permitted. Academic applications may move research/output/methods ahead of clinical experience. Report ongoing training, unknown completion/board outcomes and self-reported language truthfully. Recommendations and completed task checkboxes are not achievements. Never silently promote resident to specialist, pending exam to passed or old unverified claim to current eligibility.

PDF export provides selectable English text with headings/page numbers and no dependencies or upload. Unsupported Unicode uses an explicit browser print-to-PDF view so every character survives; the UI labels Save as PDF accurately. TXT preserves the source text. Existing immutable CV versions and defaults remain owner-controlled; exporting does not change facts, verify credentials or send a document.
