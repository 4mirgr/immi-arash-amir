# Public discovery and contact engine

This engine runs within existing Workers Free services; it needs no additional search API key or paid subscription. Fixed source collection now has23 adapters, including five directly checked clinical recruitment sources (GP-CLINICAL-EXPANSION.md). The hourly collector still visits three sources per run; the normal full rotation is about8hours. This is finite coverage, not an exhaustive index of every Australian practice, private group or social profile.

Actually retrieved HTML/plain text is parsed for emails, labelled phones, public social links, websites and explicitly stated organization identities. Every fact keeps sourceURL, readAt, exact quote, method and application/general/unknown role. Hidden content, login/action paths and privacy/DPO recipients are excluded. JSON-LD is parsed as data, never executed; only explicit JobPosting structures can establish an employer-name statement. Flat text uses local match context so an unrelated privacy footer cannot suppress clinical contacts elsewhere.

The reading queue follows at most3 relevant same-official-host links per parent and at most1 depth. Linked-page contacts retain that relation and their own receipt; they never silently become an advertisement-specific recruiter. First reading slot prefers Australian clinical pages missing an email; the second prefers Italy, with fallback in both slots. Existing cap2pages/run, robots/TLS limits,7day refresh and bounded transient retries remain. PDF attachments and authenticated/private/social-network crawling are not added.

Public-page-enrichment-schema.sql and public-discovery-ai-schema.sql go ONLY in OPPORTUNITY_DB before deployment. Extraction is transactional with page receipts; stale, changed, foreign-owner and historical-edition facts cannot be reused as current contacts. Old public text was backfilled; actual new employer pages were read again. Snapshot2026-11-04:1142 receipt-matched enriched pages;439 distinct email strings,60 phone strings,7 social URLs and287 websites. These are public contact observations across AU/IT, not verified identities or439job offers; repeated occurrences remain provenance records.

Optional PUBLIC_DISCOVERY_AI_ENABLED=true uses the existing Workers AI binding and llama-3.1-8b-instruct-fp8. Hard shared budget4attempts/UTCday, max3600public input characters and260output tokens/run. Failures reserve budget. The model can select at most3 quotations; only verbatim source substrings are stored. It cannot supply contact values, eligibility, CV achievements or acceptance probabilities. No private CV, mailbox or OAuth data is sent to this public selector. One actual public inference produced verified quotations before deployment; the deterministic engine works when inference is unavailable.

Opportunity fit prioritizes explicit GP/IMG/Level1 evidence, restrictions and unknowns. Level2+ requirements remain restrictions for the Level1 target; no percentage is inferred. Optional authenticated own-profile readiness reads only that profile once per response, without public storage or inference. CV and exam statements remain self-reported pending original documents, dates and regulator assessment. Fit sorting is explicitly limited to the returned page, not a global acceptance ranking.

Per-opportunity mail now admits receipt-validated public contact evidence (including explicitly labelled related-page contacts). Recipient source/role is displayed. Defaults never send by themselves. After preview and explicit review, one send button queues the fixed snapshot and immediately dispatches only one new, unambiguous matching queue item from that owner's selected Gmail. Reused/ambiguous results, changed sender/content/source and suppression stop transport; there is no automatic retry. All development transport checks use mocks.
